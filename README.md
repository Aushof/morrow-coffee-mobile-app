# Morrow Coffee — Mobile Ordering App

## Tentang Proyek

Morrow Coffee adalah aplikasi mobile untuk pemesanan makanan dan minuman di coffee shop. Aplikasi ini dikembangkan sebagai proyek kelompok mata kuliah Pemrograman Mobile.

## Tujuan

Memudahkan pelanggan memesan menu langsung dari meja melalui pemindaian QR Code, serta membantu kasir mengelola pesanan dan memantau status transaksi.

## Fitur Pelanggan

* Scan QR Code untuk mengidentifikasi meja.
* Konfirmasi nomor meja.
* Melihat menu makanan dan minuman.
* Melihat detail produk dan harga.
* Menambahkan produk ke keranjang.
* Memeriksa pesanan dan total harga.
* Memilih metode pembayaran.
* Menampilkan QRIS untuk pembayaran.
* Melihat konfirmasi dan status pesanan.

## Fitur Kasir

* Dashboard ringkasan pesanan.
* Melihat dan mengelola pesanan masuk.
* Memperbarui status pesanan.
* Memantau ketersediaan meja.
* Melihat informasi pembayaran dan laporan transaksi.

## Teknologi

* Flutter
* Dart
* Git dan GitHub
